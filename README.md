# Portfólio — Heitor Ivonica

Portfólio pessoal de **Heitor Ivonica**, Desenvolvedor Fullstack com foco em Front-end.

Feito com **React**, **CSS puro** e **JavaScript**, usando **Vite**. Responsivo para desktop, Android e iOS.

🔗 **Acesse online:** https://portifolio-heitor-chi.vercel.app/

## Tecnologias

- React 18
- Vite
- CSS puro (sem frameworks)
- JavaScript

## Como rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:5173` no navegador.

## Estrutura

- `src/components/` — seções do site (Header, Hero, Sobre, Habilidades, Projetos, Contato, Footer)
- `src/data/` — dados editáveis (perfil, habilidades e projetos)
- `src/index.css` — estilos e cores
